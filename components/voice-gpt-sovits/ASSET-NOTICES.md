# Voice component licenses and preparation

The Buddy plugin code license in LICENSE.md does not relicense models, Python, FFmpeg, third-party distributions, user reference recordings, or cloud services. Model weights and Python environments are not embedded in these small ZIPs: signed assets.json fixes every component path, size, SHA-256 and available pinned source. Prepare only the selected local engine plus the one shared runtime. MiniMax mode requires the shared Python/ASR/cloud runtime and an explicitly configured key/voice binding; it does not require Breeze or GPT-SoVITS weights. It never silently falls back to another engine or downloads a second TTS engine.

The audio tokenizer retains its own license. GPT-SoVITS source is MIT; pretrained models and included dependencies retain their own notices. Python and site-packages retain python/LICENSE.txt and distribution dist-info/licenses. The GPT component downloads the fixed Gyan FFmpeg 8.1.2 full-build archive from its upstream release and verifies the archive and selected files; the AI Buddy release does not mirror this FFmpeg archive. Retain the supplying distribution notices. This preparation path does not state a separate redistribution authorization.

This engine package includes only the approved 11-character preset references documented in PRESET-SOURCES.md at the source repository root. User recordings remain private data and are not included. Bundled full references stay local until the user explicitly confirms cloud cloning. A local reference profile does not create or promise the same timbre on MiniMax: use the role's explicitly selected MiniMax voice binding. API keys are not included. Hosted service terms are separate from self-hosted model licenses.

This source prepares voice package 1.0.2 for AI Buddy ^2.0.11. Public catalog signing and publication are separate release steps. Package metadata does not relicense any model assets or third-party distributions.
